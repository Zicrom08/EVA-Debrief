Formats acceptés :
· Historique de parties : { "data": { "cursorAfterhGameHistory": { "nodes": [...] } } }
· Ton profil / stats de saison : { "data": { "getPlayerByUserId": { ... } } }
· Profil public d'un autre joueur : { "data": { "getPublicPlayerByUsername": { ... } } }
· Export du collecteur : { "nodes": [...], "playerStats": [...] }
· Un simple tableau de parties.

Les stats de profil sont des totaux cumulés : importe le même profil à plusieurs dates différentes pour que l'onglet Profil puisse tracer son évolution.

Sauvegarde : tes données sont stockées sur le serveur (dans sa base de données), pas dans ce navigateur — elles sont donc visibles depuis n'importe quel appareil qui accède à ce serveur, et survivent à un vidage de cache. La déduplication (parties déjà connues, profils identiques) est gérée par le serveur, donc tu peux réimporter les mêmes fichiers plusieurs fois sans risque.
